THE PROJECT

A practical introduction to connected data.

HospitalManagementSystem is a menu-driven Java console application for keeping track of patients, doctors, and appointments. It brings together core Java programming and relational database concepts in one focused project.

Through JDBC, the application communicates with a MySQL database named hospital. It can add and view patient records, list doctors and specializations, and book appointments while checking related IDs and doctor availability for a selected date.
