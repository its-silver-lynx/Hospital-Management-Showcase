# Hospital Management System Showcase

A responsive static website presenting my console-based Hospital Management System built with Java, JDBC, and MySQL.

The showcase introduces the project's purpose, core features, technology stack, database structure, and learning outcomes. It links to the original source-code repository for visitors who want to explore the implementation.

## Project

**Source repository:** https://github.com/its-silver-lynx/Hospital-Management_JDBC_Project

The application provides a menu-driven console interface for adding and viewing patients, viewing doctors and their specializations, and booking appointments by date.

## Website Features

- Responsive layout for desktop, tablet, and mobile screens
- Tyrian Purple and Heliotrope Purple visual theme
- Overview of the Java project and its main features
- Technology stack and database structure sections
- Clear link to the original Java project repository
- Lightweight static website with no backend or database connection

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript, if required for navigation or small interactions
- GitHub Pages for static hosting

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.

No build step or package installation is required.

## Publish with GitHub Pages

1. Open the repository's **Settings** on GitHub.
2. Select **Pages**.
3. Under the build and deployment settings, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Save the settings and wait for GitHub Pages to publish the site.

The published address will be:

https://its-silver-lynx.github.io/Hospital-Management-Showcase/

## Scope

This repository contains a presentation website only. It does not run the Java application, connect to MySQL, or provide hospital-management functionality in the browser. To run the actual application, visit the source repository and follow its setup instructions.
